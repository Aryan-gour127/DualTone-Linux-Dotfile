# KDE shortcuts and window management

This page documents a simple set of keyboard shortcuts for a clean, efficient Plasma workflow.

## Recommended shortcut categories

### Application launcher

- `Alt+Space` or a custom launcher shortcut

### Terminal

- `Ctrl+Alt+T` to open Kitty or another terminal

### Window movement

- `Alt+F7`: move window
- `Alt+F8`: resize window
- `Alt+F1`: window operations menu

### Workspace switching

- `Ctrl+F1` to `Ctrl+F4` depending on your layout

### Screen capture

- `Print` for full screen capture
- `Shift+Print` for selected region

### System actions

- `Ctrl+Alt+L` for lock screen
- custom keybinding for brightness and volume if needed

## Keep shortcuts consistent

Document the keybinding in a small note or screenshot so that the layout is reproducible and easy to maintain. Fewer, clearer shortcuts are better than many poorly remembered ones.
