# Panels and widgets

This document explains a minimal panel layout for KDE Plasma.

## Recommended panel layout

Keep the panel narrow and functional. A typical setup includes:

- application launcher
- task manager
- system tray
- clock
- notification area
- quick controls for volume and brightness

## Widget principles

- prefer utility over decoration
- avoid excessive third-party widgets unless they are essential
- keep spacing consistent
- use a clean, monochrome visual language

## Panel behavior

- use one main panel when possible
- keep panels uncluttered
- set a readable font size
- adjust icon size to avoid crowding
- hide rarely used widgets

## Desktop effects

Keep effects minimal for a stable desktop experience:

- disable unnecessary animations if performance is limited
- reduce blur and visual noise in low-powered systems
- enable only the effects that improve usability
