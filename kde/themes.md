# KDE themes

This document explains how to manage the visual identity of a minimal KDE Plasma desktop.

## Theme layers

A KDE setup includes several related but separate elements:

- global theme
- color scheme
- application style
- window decoration
- icon theme
- cursor theme
- font configuration

## Light and dark variants

### Light variant

Use:

- white background
- charcoal text
- muted gray borders
- simple widgets

### Dark variant

Use:

- charcoal background
- soft white text
- subtle gray dividers
- restrained panel and window styling

## Recommended workflow

1. choose the wallpaper first
2. define the color scheme
3. adjust application style
4. set the icon set and cursor
5. review window decoration and spacing
6. fine-tune fonts and widget contrast

## Practical notes

- not every app follows the global theme exactly
- custom GTK themes may override the desktop appearance in some applications
- keep the Pallet minimal to avoid visual noise
- prefer readability over decorative effects
