# Screenshots

This directory is a placeholder for future desktop and configuration screenshots.

The repository intentionally avoids claiming a tested desktop setup without real evidence. If you capture screenshots later, add them here and document them clearly.

Suggested files:

- `desktop.png`
- `terminal.png`
- `launcher.png`
- `system-settings.png`
- `panels.png`

Recommended capture workflow:

1. Open KDE Plasma in a clean desktop state.
2. Capture the relevant area with Spectacle or another screenshot tool.
3. Save the image in this folder.
4. Add a short note to the main README linking to the result.

Do not add fabricated screenshots or claim that a setup works without testing it on a real system.
