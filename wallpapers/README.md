# Wallpapers

This directory is reserved for wallpaper assets and notes.

Use a simple monochrome wallpaper or a subtle textured image to match the dual-tone desktop philosophy.

Recommended approaches:

- solid white or charcoal background
- grayscale gradient with minimal contrast
- subtle geometric or architectural texture
- low-noise pattern that does not compete with desktop widgets

Keep the file size reasonable and document any source or license information in a README or adjacent note if you add third-party artwork.

## Example usage

```bash
ls wallpapers/
```

Place wallpaper files here and apply them in KDE Plasma through System Settings.
